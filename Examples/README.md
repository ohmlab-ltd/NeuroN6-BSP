# Examples

Each example is its own STM32CubeIDE project. **Standalone examples** show one
thing each: a `setup()` and a `loop()`. **Bench images** are larger: the test
console, video, thermal and neural networks over USB and Wi-Fi, BLE and HTTPS.

## Standalone examples

All have run on a Neuro N6. The last column is what the console showed.

| Example | Shows | Seen |
|---|---|---|

| [BlinkWithoutDelay](BlinkWithoutDelay/) | the same without blocking `loop()` | the same |
| [DigitalReadSerial](DigitalReadSerial/) | the USER button on the console | `released`, ten a second |
| [ButtonInterrupt](ButtonInterrupt/) | the button counted by interrupt | a count when pressed |
| [AnalogReadSerial](AnalogReadSerial/) | A0 in counts and millivolts (1.8 V full scale) | a floating pin near 865 mV |
| [Fade](Fade/) | PWM on the red LED | breathing, 3 s a cycle |
| [RgbLed](RgbLed/) | the eight RGB LED colours | each named as it changes |
| [WireScanner](WireScanner/) | the addresses on the sensor bus | the four on-board parts |
| [ReadAcceleration](ReadAcceleration/) | accelerometer and gyroscope | gravity at 999 mg |
| [ReadMagneticField](ReadMagneticField/) | the magnetometer | 962 mG |
| [ReadDistance](ReadDistance/) | time-of-flight distance (OV5640 carriers) | 691 to 711 mm, status 0 |
| [SpeakerTone](SpeakerTone/) | a tone, a second on and off | `tone` / `silence` |
| [MicrophoneLevel](MicrophoneLevel/) | a microphone level bar | the bar moving |
| [LcdColourBars](LcdColourBars/) | colour bars on the panel | runs |

Every standalone `main.c` ends with the same scaffolding, generated by
`harness/examples/exgen.py`:

- the watchdog is armed first, and its early warning sends the board to the boot loader;
- a watchdog reset goes to the boot loader;
- `delay()` and `loop()` service USB and the watchdog, and a `b` from the host reboots into the boot loader.

A fault lands in the boot loader too, unless the application defines
`BSP_FaultCallback`. `print()` is `BSP_COM_Printf`, which drops output when no
host has the port open.

## Building and running

- Each example's `STM32CubeIDE/` folder holds an `Appli` project (the application) and an `FSBL` project. `BSPTest` and `Camera_JpegStream_USB` also have `Appli_FreeRTOS`.
- The board already runs a boot loader, so only `Appli` needs uploading. The BSP and middleware are linked from the repository, never copied.
- **In STM32CubeIDE 2.2.0:** use *File > Import > Existing Projects into Workspace*, select the example's `STM32CubeIDE` folder, and leave *Copy projects into workspace* unticked. Build `Debug`. The image is `STM32CubeIDE/Appli/Debug/<Example>_Appli_Trusted.bin`.

From the command line:

```bash
bash harness/examples/cubebuild.sh Blink      # build headless; --all for every example
python harness/examples/runex.py Blink        # upload, watch the console, return to the boot loader
python harness/n6flash.py <image>_Trusted.bin # upload any image to the application slot
```

## Bench images

| Example | What it does |
|---|---|
| [BSPTest](BSPTest/) | Test console, one command per BSP module, driven by `harness/n6test.py` |
| [Camera_JpegStream_USB](Camera_JpegStream_USB/) | VGA JPEG at 60 fps to Neuro Studio over USB |
| [Camera_UvcStream_USB](Camera_UvcStream_USB/) | The same as a standard USB camera |
| [Camera_UvcStream_USB_FreeRTOS](Camera_UvcStream_USB_FreeRTOS/) | That camera under FreeRTOS |
| [Camera_UvcStream_VD66GY_USB](Camera_UvcStream_VD66GY_USB/) | USB camera with the VD66GY global-shutter sensor (thermal carrier), up to 88 fps |
| [Camera_UvcStream_VD65G4_USB](Camera_UvcStream_VD65G4_USB/) | USB camera with the VD65G4: 640x480 at 60 fps |
| [Thermal_Stream_USB](Thermal_Stream_USB/) | Lepton thermal video to Neuro Studio, about 9 fps |
| [Camera_GlobalShutterThermal_USB_FreeRTOS](Camera_GlobalShutterThermal_USB_FreeRTOS/) | VD66GY JPEG at 60 fps, Lepton thermal and motion data together |
| [Camera_Nia416Stream_USB_FreeRTOS](Camera_Nia416Stream_USB_FreeRTOS/) | NIA Triad-416 detector: XGA at 30 fps over USB, with detections |
| [Camera_Nia416Stream_WiFi_FreeRTOS](Camera_Nia416Stream_WiFi_FreeRTOS/) | The same detector over Wi-Fi from the board's own access point (2.4 GHz) |
| [Camera_PalmDetect_USB_FreeRTOS](Camera_PalmDetect_USB_FreeRTOS/) | MediaPipe palm detector; the smallest network example (Apache-2.0 model) |
| [Camera_HandLandmarks_USB_FreeRTOS](Camera_HandLandmarks_USB_FreeRTOS/) | Palm detector, then 21 hand landmarks (Apache-2.0 models) |
| [Camera_YoloV8Seg_USB_FreeRTOS](Camera_YoloV8Seg_USB_FreeRTOS/) | YOLOv8n instance segmentation. **AGPL-3.0 model and `main.c`** |
| [Camera_YoloV8Pose_WiFi_FreeRTOS](Camera_YoloV8Pose_WiFi_FreeRTOS/) | YOLOv8n pose over Wi-Fi, built to run unattended. **AGPL-3.0 model and `main.c`** |
| [WiFiApi_FreeRTOS](WiFiApi_FreeRTOS/) | Console over the whole Wi-Fi API, driven by `harness/bench/n6wifiapi.py` |
| [BleBeacon_FreeRTOS](BleBeacon_FreeRTOS/) | A BLE beacon |
| [BlePeripheral_FreeRTOS](BlePeripheral_FreeRTOS/) | A BLE device with GATT services and an echoing UART service (NimBLE) |
| [WiFiTls_FreeRTOS](WiFiTls_FreeRTOS/) | HTTPS server and client over Wi-Fi (Mbed TLS) |

The two YOLOv8 examples are skipped by `harness/compile.sh` and
`cubebuild.sh --all` unless `NEURON6_BUILD_RESTRICTED=1`. Read their READMEs
before shipping anything built from them.
