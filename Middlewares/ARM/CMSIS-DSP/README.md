# CMSIS-DSP headers

The headers of Arm's CMSIS-DSP 1.10.0, from CMSIS 5.9.0, copied verbatim.
Apache-2.0 (`LICENSE.txt`).

Only the headers are carried. `Middlewares/NeuroN6/PostProcess` includes
`arm_math_types.h` and `arm_math.h` for their types, such as `float32_t`;
no CMSIS-DSP function is compiled or linked.
